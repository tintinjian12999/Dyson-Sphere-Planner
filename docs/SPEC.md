# 第一版：工廠區塊與建造配置

確認日期：2026-09-24。

## 已確認範圍

- 延伸 0fuz/dsp-calc，保留來源與授權。
- 輸入單一產品與每分鐘產量，自動生成工廠區塊與供需連線。
- 每區塊一道配方，可配置多台設備；一個區塊可拆成多組產線。
- 固定模板依流量擴展，不任意求解土地形狀。
- 建造接口支援傳送帶直出、行星物流站、星際物流站，可設定全域預設與區塊覆寫。
- 行星物流站 4 槽、星際物流站 5 槽；優先容納配方原料與產品，增產劑超出槽位時使用獨立外接傳送帶。傳送帶模式不建立物流站，保留所有原料與產品端點。
- 全域設備可選輸送帶／分揀器 Mk.I–III、製造台 Mk.I–III／重組式製造台、電弧／位面／負熵熔爐、化工廠／量子化工廠、矩陣／自演化研究站。舊計畫維持原本設備預設。
- 全域增產預設，可按區塊覆寫等級、模式與停用狀態。
- 原料外部供應；增產劑視為額外外部耗材並列明數量。
- 涵蓋快照中全部 173 種實體物品；151 種有製程，22 種外部供應；不把科技研究項目列為產品。600 個電磁渦輪／分鐘保留為回歸案例。
- 產能、物料平衡、輸送帶、分揀器及物流站槽位必須互相一致。

## 預留擴充

- 計算引擎已預留既有供應量。先合計全部下游需求，再扣除可分配的既有供應，不足部分展開製造；共享上游不會被錯誤整段刪除。第一版沒有此項編輯介面。
- 區塊保留 planetId；目前僅 home，不提供跨星球計算。
- template/cell 與運輸 edges 分開，未來可加入星球分配與真正的遊戲藍圖序列化。

## 可用介面

- 生產網路：選取、拖曳、縮放、平移、自動排列、專注畫布。
- 區塊配置：分組配置、物料與分揀器方向、槽位供需設定、滿載帶速檢查。
- 建造清單：全計畫建築數量、每分鐘外部供應及剩餘共同產物。
- 接口設定與區塊覆寫隨計畫保存；舊版缺少接口欄位的計畫預設為星際物流站。
- 裝置本地儲存、計畫 JSON 匯入／匯出、獨立 SVG 配置圖、CSV 清單。

## 驗收狀態的界線

數學及模板模型檢查不等同遊戲內建造驗證。模板必須保留「遊戲內待驗證」標示，直到實際遊戲測試有記錄。不得把 SVG 配置圖稱為可匯入遊戲的藍圖。

## 多列排列擴充

- 三種排列：單列、三列分流（共用主幹）、三列獨立供料。
- 多列每列設備上限可設為 1–60 台（預設 4）；全域設定與區塊覆寫都會保存。實際分組按帶速自動縮減，末組平衡分配設備。
- 分流不提高共用單帶容量；獨立供料逐列校核，輸出不合流。物流站模式獨立供料每列一站。
- 顯示列內配置、分流器、各列產量與主幹／分支容量；清單及 SVG／CSV／JSON 同步更新。
- 分流的跨列連接僅為接線示意，尚未求解格線路徑；該網路不計入傳送帶估算。

## 全產品擴充

- 可依中文名稱、英文名稱或產品 ID 搜尋，分類為建築設備、材料產品、外部資源掉落物。
- 每種產品使用無循環的預設配方路線，同一製程合併需求；多產物全部記帳，先抵扣其他製程需求再列剩餘。
- 特殊設備及超過三原料的配方提供供需示意、多座站槽位分組與吞吐估算；不宣稱有可直接施工的格線模板，未知帶長與電力塔在 UI／CSV 明列。
- 共同產物、槽位與設備等級須同步反映於 SVG、CSV 與 JSON。全部產品可選為目標，但資源／掉落物只顯示外部需求。
- 配方切換、循環製程及跨星球物流不在此次擴充範圍。
